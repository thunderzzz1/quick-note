## 问题与修复记录

### #1 捕获窗无法输入文字

- **现象**：呼出捕获窗后，编辑区是空的，任何键盘输入都无效（第 2 项验收不通过）
- **根因**：编辑器（Milkdown Crepe）的初始化写在了 React 的 `useMemo` 里；`useMemo` 在渲染期间执行，此时 `hostRef.current` 还是 `null`（ref 要等 DOM 提交后才挂上），而空依赖数组导致它永远不会再执行——编辑器从未创建
- **修复**：把初始化移到 `useEffect`（挂载后 ref 已就绪），并在创建完成后自动聚焦编辑器（`src/components/capture/CaptureWindow.tsx`）
- **复验状态**：待人工复验——重新 `npm run tauri dev`，呼出窗口应可直接输入中文/列表/加粗

### #2 每次重启仍出现"选择数据目录"向导

- **现象**：选过数据目录后，完全退出再启动，向导又出现，且启动前有一段白屏
- **根因**：启动逻辑永远读取默认目录（`Documents\QuickNote`）的配置；用户选择的数据目录只存在于当前进程内存，没有持久化，重启即丢失，`configured: true` 从未被读到
- **修复**：新增数据目录指针文件（`%APPDATA%\QuickNote\app.json`），首启选择/迁移目录时写入；启动时先读指针再加载配置（`src-tauri/src/config.rs`、`commands.rs`、`lib.rs`）
- **附带**：加载期间白屏改为"QuickNote 加载中…"占位（`src/App.tsx`）
- **复验状态**：待人工复验——托盘退出后重新 `npm run tauri dev`，应直接进入主界面；`%APPDATA%\QuickNote\app.json` 应存在且指向你的数据目录

### #3 关闭捕获窗后快捷键无法再次呼出

- **现象**：快捷键呼出捕获窗后，点窗口右上角 X 关闭，再按快捷键没反应
- **根因**：捕获窗带标题栏，X 默认是"销毁窗口"而不是"隐藏"；窗口销毁后快捷键回调对已销毁窗口执行 show 无效
- **修复**：拦截关闭请求，主窗口和捕获窗的 X 都改为"隐藏"（托盘常驻应用的标准行为），真正退出只能走托盘菜单（`src-tauri/src/lib.rs`）
- **复验状态**：待人工复验——点 X 后再按快捷键应能再次呼出

### #4 增加主动保存入口

- **需求**：不希望只能靠失焦/等自动保存，需要主动保存
- **实现**：捕获窗顶部新增"保存"按钮和"已保存 时间/保存中…"状态提示；支持 Ctrl+S（`src/components/capture/CaptureWindow.tsx`）
- **复验状态**：待人工复验
